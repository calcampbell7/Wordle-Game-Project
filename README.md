Wordle Game

Setting up the Game
1) Clone the repository
2) In the root directory, use "make" command to produce executable files
3) run "./wordgame" to begin game

How to play
-There is a six-letter word that has been selected at random. You are trying to guess this word.
-Guess a six letter word. Each letter of your guess will then be displayed in a colour-coded format.
-If the letter is Green, then the letter is in the word, and is in the correct position.
-If the letter is Yellow, then the letter is in the word, but is in the wrong position.
-If the lette is grey, then the letter is not in the word.
-You have six guesses, good luck!
